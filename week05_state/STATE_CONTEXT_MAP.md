# 상태 계약과 컨텍스트 지도

## 상태 계약

| 값 | 원본/계산 | 초기값 | 변경 이벤트 | 읽는 화면 | 소유자 |
|---|---|---|---|---|---|
| 완료 여부 | 원본 | 각 항목 false | 완료버튼 클릭 | TaskPage | _TaskPageState |
| 남은 할 일 수 | 계산 | 전체 항목의 수 | 원본 변경에 따라 재계산 | TaskPage | 별도 저장 없음 |

## 상태 흐름도

```text
사용자 입력 → 이벤트 함수 → 원본 상태 변경 → 계산값 → 화면 표시
완료 버튼 → _toggleDone(index) → _done 변경 → _remaining 계산 → 카드·상단 숫자
```

## 파일·화면·상태·데이터 지도

| 범주 | 이번 기능의 최소 관련 대상 | 변경 시 다시 확인할 것 |
|---|---|---|
| 파일 | `lib/main.dart` | `lib/main.dart` |
| 화면 | `TaskPage` | `TaskPage` |
| 상태 | 완료 여부 | _toggleDone 함수 실행 시 setState가 호출되는 지 |
| 데이터 | 할 일 제목과 완료 여부 | _title과 _done 리스트의 데이터 항목이 엇갈리지 않는지 |
| 증거 | `evidence/` 화면 캡처 | `evidence/`의 화면 캡처 이미지들 |

## 변경 영향

요구 “완료 버튼을 다시 누르면 미완료로 돌아온다”를 구현할 때 바꿀 코드와 재검증할 화면을 한 문장씩 적는다.
